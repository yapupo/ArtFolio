# ArtFolio — Repositório de Artes e Gestão de Comissões

Plataforma web desenvolvida para centralizar o portfólio de artistas visuais e organizar o fluxo de criação e solicitação de comissões em um único lugar.

## Sobre o projeto
O ArtFolio resolve a fragmentação comum no trabalho de artistas independentes, reunindo a vitrine de obras e o gerenciamento de pedidos de comissão em uma interface direta, prática e responsiva.

## Funcionalidades
- **Repositório de Artes:** organização e exibição centralizada de ilustrações e trabalhos autorais.
- **Gestão de Comissões:** estrutura voltada para a criação, padronização e acompanhamento de pedidos de arte sob encomenda.

## Stack utilizada
- TypeScript
